# OniLink 0.3 Operations Modules

The 0.3 beta adds OniFlow, continuity/limbo, quarantine, journey tracing, OniForge compatibility
evidence, dynamic fleet/canary/blue-green controls, presence/roles/support, pack scanning, the iOS
PWA, and VAPID Web Push to the existing single-container dashboard.

The complete configuration, security boundaries, examples, permissions, rollout procedure, and
troubleshooting notes are maintained in the repository's
[Expansion Modules guide](https://github.com/TheNINJALLO/OniLink/blob/main/docs/EXPANSION_MODULES.md).

Safe defaults matter: only journey summaries and scanning start enabled. Limbo, quarantine, fleet,
workflow, support, control, and notifications remain off until their backend names, allowlists,
secrets, and limits are configured.
