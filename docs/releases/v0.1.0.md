# OniLink 0.1.0

OniLink 0.1.0 is the first normal, non-prerelease application release. It promotes the verified Candidate 3 application build and ships the complete proxy, control plane, native Linux bridge, Geyser extension, self-updating Pterodactyl egg, configuration examples, compatibility evidence, and checksum manifest as one release bundle.

## Highlights

- Authenticated Bedrock proxying with backend-bound, short-lived, replay-protected `OniForward` claims.
- Exact-profile native OniBridge support for BDS `1.26.44.3` Linux x86-64 with Endstone `0.11.9`.
- OniBridge-Geyser support for Geyser `2.11` and Java-backed routes.
- Embedded operations dashboard with accounts, roles, TOTP, live players, backend health, transfers, broadcast controls, configuration editing, logs, metrics, audit records, and redacted support bundles.
- Guided **Add BDS Backend** workflow that creates a unique protected key, updates OniLink safely, and downloads a matching `onibridge.toml` plus key file.
- Self-updating PTDL v2 egg that verifies every downloaded JAR against `SHA256SUMS`, preserves configuration, and keeps the previous JAR for rollback.
- Linux builds compatible with glibc 2.35 or newer and guarded against mixed `libstdc++`/libc++ ABI failures.

## Fixed since Candidate 2

- Broadcast-to-all and dashboard account-creation forms no longer attempt to reset a null browser event target after an asynchronous request.
- Linux native builds no longer depend on the incompatible GCC `std::__cxx11` ABI.
- Secret files generated by the backend wizard are automatically restricted to owner-only access before OniBridge reads them.

## Upgrade from Candidate 3

Pterodactyl installations using `start-onilink.sh` download `v0.1.0` automatically after the release is published and checksum-verified. Restart the OniLink container once, then refresh the dashboard page.

The application protocol, current native library code, keys, and configuration format are unchanged from Candidate 3. The released egg now bootstraps `v0.1.0`, and the Linux compatibility manifest records the already-passing profile-specific hook harness. Keep normal backups and verify the downloaded directory before replacing files.

## Native profile status

The `v0.1.0` application release is stable, but that label does not bypass OniBridge's exact-profile gates. The included Linux profile remains `production_ready=false` because formal human profile review and the complete recorded live acceptance matrix are still open. It therefore still requires the explicit `allow_unreviewed_profile=true` opt-in and fails closed on unknown BDS, Endstone, hash, ABI, or hook details.

Do not enable unknown-version bypasses or describe the current native profile as production-approved. See [Compatibility](../COMPATIBILITY.md) and [Testing](../TESTING.md) for the exact evidence and remaining matrix.

## Verify downloads

Download the complete release directory and verify every payload before installation:

```bash
gh release download v0.1.0 \
  --repo TheNINJALLO/OniLink \
  --dir onilink-release
cd onilink-release
sha256sum -c SHA256SUMS
```

The final artifact checksums and GitHub Actions provenance are recorded here after the release bundle build completes. No Mojang/Microsoft BDS archive or executable is distributed.
