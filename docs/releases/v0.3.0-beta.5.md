# OniLink 0.3.0 Beta 5

OniLink `0.3.0-beta.5` prepares the complete stack for Minecraft Bedrock Server `1.26.45.1` and
Endstone `0.11.10`. It adds the released `1.26.45` network protocol `2169`, rebuilds OniBridge
against Endstone's exact signed source tag, and generates separate hash-bound Linux and Windows
native profile candidates from the official server executables.

> [!CAUTION]
> The BDS 1.26.45.1 profiles are candidates until their real-server startup, proxied login,
> verified-XUID, disconnect, and clean-shutdown checks pass. Candidate status is intentionally
> separate from the production-approved Linux BDS 1.26.44.3 profile.

## Added

- A dedicated protocol-2169 codec for Bedrock 1.26.45.
- Per-player routes from 1.26.40-1.26.44 protocol-2168 clients and the 1.26.50 protocol-2192
  Preview client to a protocol-2169 backend.
- Authenticated `GameVersion` refinement for the two releases that share protocol 2168, preserving
  the different 1.26.44 SetScore removal layout without changing another player's live codec.
- Exact Linux and Windows BDS 1.26.45.1 acquisition locks, generated adapters, and candidate
  profiles. No BDS executable or archive is included in the repository or release.

## Endstone 0.11.10

- OniBridge is pinned to signed Endstone commit
  `8f84d6f5b556916597ed5b6b71329b2ed3ca8fc8` and refuses another Endstone runtime version.
- Endstone now leaves IPv6 disabled unless `[network] ipv6 = true` is set in `endstone.toml`.
- The canceled `PlayerDropItemEvent` main-hand restoration fix requires no OniBridge change.
- Changed BDS login symbols require the new exact native adapter; a 1.26.44 plugin must never be
  renamed or reused with BDS 1.26.45.1.

See the [Endstone update audit](../ENDSTONE_0_11_10_AUDIT.md) for hashes and source-level findings.

## Upgrade for candidate testing

1. Back up `config.properties`, `dashboard/`, `cache/`, `onibridge.toml`, worlds, and plugin data.
2. Upgrade the backend to exact BDS `1.26.45.1` and Endstone `0.11.10`.
3. Replace OniLink with the beta 5 JAR and replace OniBridge with the beta 5 artifact whose filename
   names BDS `1.26.45.1` and the correct operating system.
4. Keep `backend.protocol=auto`. If probing is unavailable, use
   `backend.<name>.protocol=1.26.45`.
5. For a controlled candidate test only, set `required_profile` to the profile ID printed by the
   matching plugin and set `allow_unreviewed_profile=true`. Do not use that override on an exposed
   production backend.
6. Confirm the hook-active line names BDS 1.26.45.1 and Endstone 0.11.10, then complete the live
   checklist before requesting profile promotion.

Existing secrets, key IDs, bridge IDs, backend names, and player data do not need migration.
