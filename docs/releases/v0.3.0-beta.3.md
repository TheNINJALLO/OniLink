# OniLink 0.3.0 Beta 3

OniLink `0.3.0-beta.3` adds a preview cross-version path for Minecraft Bedrock `1.26.50` clients
while keeping BDS, Endstone, and OniBridge on the exact `1.26.44.3` backend profile. Protocol
selection is per player session: 2168 and 2192 clients can use the same running OniLink listener
without a global mode switch, proxy restart, or backend downtime.

This is a prerelease. The 2192 codec follows Preview `1.26.50.26`; final public client acceptance
is required before this path is production-ready. The Linux BDS `1.26.44.3` + Endstone `0.11.9`
OniBridge profile remains production-approved. The Windows profile remains a candidate requiring
the evidence described in [Compatibility](../COMPATIBILITY.md).

## Highlights

- Accept protocol 2168 and 2192 clients independently on the same listener.
- Translate 1.26.50/2192 sessions to a 1.26.44/2168 backend without changing the backend version.
- Select the 1.26.44 SetScore hotfix dialect from the backend pong while retaining explicit
  1.26.40 support for servers on the earlier 2168 layout.
- Drop new packets and fields when no reviewed 2168 representation exists instead of guessing.
- Manage optional modules from the owner-only **Platform -> Modules** dashboard page, including
  dependency checks and clear running/configured/restart-pending state.

## Upgrade

1. Back up `config.properties`, `dashboard/`, `cache/`, and the matching OniBridge configuration.
2. Set the Pterodactyl update channel to `beta`, or pin `ONILINK_VERSION=v0.3.0-beta.3`.
3. Restart the OniLink container once so the updater can verify and install the new JAR.
4. Keep BDS, Endstone, and the installed OniBridge profile on `1.26.44.3`; no bridge key or
   configuration change is required for client protocol translation.
5. Keep `backend.protocol=auto`, or use `backend.<name>.protocol=1.26.44` when backend ping is not
   available. Do not configure the backend as 1.26.50 while it still runs 1.26.44.
6. Test a final public 1.26.50 client with the checklist in
   [1.26.50 cross-version preview](../CROSS_VERSION_1_26_50.md).

After that initial update restart, protocol choice is automatic for every new player connection.
A 1.26.50 player joining does not restart OniLink or BDS and does not interrupt existing 1.26.44
sessions.

The beta-channel updater checks published prereleases at every container start, verifies release
checksums, replaces runtime files atomically, preserves the live configuration, and keeps the last
JAR for rollback. Use `pinned` to hold this exact build.

## Verification and limitations

The release is gated by the complete Java, dashboard, Python packaging/egg/ABI, and native core
suites. Linux artifact CI also enforces the `GLIBC_2.35` ceiling and rejects mixed
`libstdc++`/`__cxx11` symbols.

The codec and serializer changes are derived from pinned Endstone Endweave and bedrock-protocol
revisions. If the final client announces a protocol other than 2192 or changes a required packet,
OniLink fails closed until a reviewed update is released. No Mojang/Microsoft BDS binary or
licensed client file is included.
