# OniLink 0.3.0 Beta 1

OniLink `0.3.0-beta.1` is the first public beta of the tenant-aware operations platform. It keeps
the established OniForward and exact native-profile security model intact while adding the approved
OniControl, Protocol Lab, OniFlow, continuity/limbo, quarantine, journey, OniForge, fleet,
OniConnect, pack-scanning, PWA, and Web Push modules to the existing proxy and dashboard.

This is a prerelease. The exact Linux BDS `1.26.44.3` + Endstone `0.11.9` OniForward profile remains
production-approved, but new control and client-visible operations retain the evidence statuses in
[Compatibility](../COMPATIBILITY.md). Modules that mutate routing or player state default off.

## Highlights

- Signed, replay-protected, scope-bound `ONICTL/1` with a separate secret from OniForward and a
  deliberately limited native action manifest.
- Owner-only Protocol Lab with timed sessions, XUID/backend/model allowlists, semantic schemas,
  negotiated-codec dry encoding, rate limits, audit, and packet-monitor origin.
- Typed workflows with manual, event, internal webhook, interval/instant schedule, condition, delay,
  approval, sequence, bounded parallel, cancellation, and frozen revision execution.
- Limbo drain/return reservations, quarantine-first immutable routing, expiring assignments, and
  privacy-aware journey timing.
- Evidence-generated protocol diffs and compatibility artifacts without automatic translator
  generation or packet-ID safety assumptions.
- Dynamic backend validation, enable/disable, revision history/rollback, sticky canaries with
  outcomes, and health/identity/capability/approval-gated blue-green promotion.
- Expiring presence, cycle-safe XUID roles, honest backend sync status, and asynchronous in-game
  support commands.
- Non-activating malicious-archive pack scanner, installable mobile PWA, and redacted VAPID Web
  Push with subscription cleanup.

## Upgrade

1. Back up `config.properties`, `dashboard/`, `cache/`, and the matching OniBridge configuration.
2. Set the Pterodactyl update channel to `beta`, or pin `ONILINK_VERSION=v0.3.0-beta.1`.
3. Restart OniLink and verify the downloaded files with `SHA256SUMS`.
4. Compare `config.properties` with `onilink.properties.example`; upgrades never overwrite the live
   configuration.
5. Keep all mutation modules disabled, configure exact backend names/limits/secrets, then enable one
   module at a time using the [0.3 Operations Modules guide](../EXPANSION_MODULES.md).
6. Install the matching `onibridge-0.3.0-beta.1-bds-1.26.44.3-linux-x86_64.so` only on the exact
   approved BDS/Endstone target.

The beta-channel updater checks published normal and prerelease GitHub releases at every container
start, verifies checksums, replaces runtime files atomically, preserves the live configuration, and
keeps the last JAR for rollback. Use `pinned` to hold this exact build.

## Verification and limitations

The source release is gated by the complete Java, dashboard, Python packaging/egg/ABI, and native
core suites. Linux artifact CI additionally builds the exact plugin with LLVM/libc++ 18, rejects
imports newer than `GLIBC_2.35`, rejects mixed `libstdc++`/`__cxx11` symbols, scans every archive for
forbidden BDS content, and publishes checksums plus OniForge JSON/Markdown evidence.

The pinned Endstone SDK does not expose reviewed implementations for `GET_ONLINE_PLAYERS`,
`CLOSE_PLAYER_CONTAINERS`, or `SAVE_WORLD`, so OniBridge returns `UNSUPPORTED`. Backend-bound
Protocol Lab models, native TLS termination, distributed presence, BDS process creation, live
RakNet migration between proxy processes, pack activation/reload, external ticket/chat/account
systems, billing, quotas, passkeys, and automatic translator generation are outside this beta.

No Mojang/Microsoft BDS binary or licensed client file is included.
