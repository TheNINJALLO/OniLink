# OniLink 0.4.0-beta.2

This beta prepares the Minecraft **1.26.50 preview / protocol 2192** client route using
Endweave's current translation rules and independently specified wire fixtures. It fixes
populated packet cases that the previous round-trip tests missed. The stable release remains
`v0.3.0`; final-release client gameplay still needs live acceptance.

## What changed

- Inventory transactions now use the 2192 source layout and preserve signed container IDs.
- Embedded item-use input reads and writes the hand byte before the item descriptor.
- Inventory responses preserve optional filtered item names; diagnostics preserve the optional
  system-category list and its presence marker.
- The new data-driven container type decodes correctly. Closes for that container are dropped
  when the older backend cannot represent them.
- Independent wire fixtures check these cases plus boss bars, dimensions, cameras, sounds,
  entity movement and both sub-chunk height maps. Nine release routes exercise joins, movement
  and populated scoreboards, including 2192 clients on 1.26.40, 1.26.44 and 1.26.45 backends.
- A daily GitHub protocol watch compares Endweave and bedrock-protocol with reviewed commit pins
  and reports changes for review. It never installs upstream code or enables unknown protocols.

## Upgrade

1. Stop the proxy and back up its configuration and data directory.
2. Download `OniLink.jar` and `SHA256SUMS` from this release, verify the checksum, and replace
   the proxy JAR. Java 21 is required. Preserve the existing configuration and data.
3. Keep backend protocol detection on `auto` and restart the proxy. Confirm the dashboard
   reports `0.4.0-beta.2`. On Pterodactyl, pin `v0.4.0-beta.2` or select the `beta` channel.
4. Test preview-client joins, movement, inventory/crafting, resource packs, chunks, commands
   and backend switching using the
   [1.26.50 acceptance checklist](https://github.com/TheNINJALLO/OniLink/blob/v0.4.0-beta.2/docs/CROSS_VERSION_1_26_50.md).

These proxy fixes do not require a backend upgrade. Existing OniBridge `0.3.0` and `0.4.0-beta.1`
builds remain compatible through OniForward v3. Matching beta 2 native artifacts are also supplied
for exact BDS **1.26.45.1** and **Endstone 0.11.10**. The Linux profile remains production-approved;
Windows remains a candidate pending its own live acceptance. Keep existing forwarding secrets.

The newer hand field cannot add off-hand behavior to an older BDS build. Protocol **2208** and
older clients on a 2192 backend are outside this release's tested route. Mojang may still change
the final 1.26.50 wire format. The
[source audit](https://github.com/TheNINJALLO/OniLink/blob/v0.4.0-beta.2/docs/CROSS_VERSION_1_26_50.md)
records the exact evidence and limitations.

## Validation

Local checks passed 533 Java tests and 92 Python tests, with two Windows platform skips.
The independent fixtures reproduced six failures before the fixes. The full Gradle `check`
and standalone JAR build passed, including the dashboard build and compatibility reports.
The tagged release workflow rebuilds and tests Java and both native platforms, validates the
exact profiles, enforces the Linux GLIBC 2.35 policy, and publishes release checksums.

This release retains the Update Center and services introduced in beta 1. To return to stable
after using those features, restore the pre-beta files and data backup; replacing only the JAR
does not undo activated protocol packages or managed-server changes.
