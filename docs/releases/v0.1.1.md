# OniLink 0.1.1

OniLink 0.1.1 promotes the exact Linux BDS `1.26.44.3` + Endstone `0.11.9` native profile to production. The repository operator approved the completed human-review and live-acceptance gates; the profile-specific native harness and Linux ABI policies also pass.

## Production promotion

- `validation_status` is now `production`.
- `hook_harness_passed`, `human_reviewed`, and `live_tested` are all recorded as true.
- `release_blockers` is empty.
- The Linux compatibility manifest reports `production_ready=true` and `release_status=production`.
- The generated native adapter is a production adapter and no longer requires the unreviewed-profile override.
- Dashboard-generated and shipped Linux TOML configurations now set `allow_unreviewed_profile=false`.

This approval is exact and narrow. It applies only to Linux x86-64 BDS `1.26.44.3`, executable SHA-256 `06effdd00067f1ae0951ee7a732398dde721728e6b18ea149b138b8e2aececa7`, Endstone `0.11.9`, and profile ID `bds-1.26.44.3-linux-x86_64-06effdd00067f1ae`. Windows, Geyser, new BDS versions, and different executable hashes retain their own gates.

## Upgrade from 0.1.0

1. Restart OniLink so `start-onilink.sh` downloads and verifies `v0.1.1`.
2. Stop the BDS/Endstone backend.
3. Replace the old native library with `onibridge-0.1.1-bds-1.26.44.3-linux-x86_64.so`.
4. Set `compatibility.allow_unreviewed_profile=false` in `plugins/onibridge/onibridge.toml`.
5. Start BDS and confirm OniBridge reports the exact reviewed profile and active native identity hook.
6. Restart OniLink if its backend route or key configuration changed.

No key rotation, world migration, player-data conversion, or bridge ID change is required. Do not leave both native library versions in the Endstone plugin directory.
