# OniLink 0.2.0 Beta 2

OniLink `0.2.0-beta.2` turns the packet monitor into a detailed, operator-controlled diagnostic
workspace and establishes OniLink as a standalone Bedrock edge system across the dashboard,
documentation, release package, and Pterodactyl panel.

This is a prerelease intended for controlled compatibility testing. Detailed captures contain
sensitive player and network data. Keep dashboard access restricted, capture only while diagnosing,
and inspect every export before sharing it.

## Detailed packet capture

- Captures decoded source and translated packet fields, chat content, authenticated XUIDs,
  player/backend endpoints, and exact uncompressed incoming packet bytes.
- Shows full packet detail only when an authorized operator opens a record, keeping the live table
  responsive while preserving useful evidence.
- Exports the complete filtered capture as JSON for offline protocol analysis.
- Retains at most 5,000 recent observations and enforces a 64 MiB per-runtime capture budget.
- Keeps provider and tenant runtimes isolated through the existing server-side authorization path.

## Token and support-bundle safety

- Login and handshake packet bodies are redacted before storage.
- Forwarding-token field names and token-shaped values are replaced even when nested in decoded
  structures or text.
- Complete forwarding tokens, login chains, and authentication secrets are never retained.
- Support bundles remain metadata-only and continue to omit chat, XUIDs, addresses, packet bodies,
  and incoming bytes even when detailed capture is enabled.

## Standalone OniLink identity

- The banner, dashboard, README, Wiki, release metadata, and Pterodactyl egg now identify OniLink as
  a standalone Bedrock edge system.
- The official product family is OniLink, OniForward, OniBridge, OniBridge-Geyser, and OniLink BDS
  tooling.
- Historical third-party names are removed from public/runtime presentation and retained only where
  required in legal attribution and the internal source audit.
- The Pterodactyl egg is now named **OniLink Bedrock Edge System**.

See [System identity](../SYSTEM_IDENTITY.md) for official naming and ownership boundaries, and
[Packet monitor](../PACKET_MONITOR.md) for capture controls, privacy rules, and translation research
workflow.

## Native compatibility

The packet-monitor and identity changes do not relax OniBridge's fail-closed native policy. The
Linux plugin remains production-approved only for the exact BDS `1.26.44.3` executable with
Endstone `0.11.9` and a maximum `GLIBC_2.35` import. Windows and Geyser retain their existing
candidate/live-validation status.

## Upgrade from Beta 1 or v0.1.7

1. Back up `config.properties`, `dashboard/`, `allowlist.properties`, and forwarding key files.
2. Download the prerelease and verify the directory with `SHA256SUMS`.
3. Pterodactyl users should reimport `egg-onilink.json` to receive the updated system name and
   bootstrap tag.
4. Set `ONILINK_UPDATE_CHANNEL=beta` to follow beta releases automatically, or use `pinned` with
   `ONILINK_VERSION=v0.2.0-beta.2` to stay on this exact build.
5. Restart OniLink, sign in to the dashboard, and open **Packet Monitor**.

No backend, tenant, key, allowlist, or player-data migration is required. The updater preserves the
active configuration and dashboard data.

```bash
gh release download v0.2.0-beta.2 \
  --repo TheNINJALLO/OniLink \
  --dir onilink-release
cd onilink-release
sha256sum -c SHA256SUMS
```

No Mojang/Microsoft BDS archive or executable is distributed.
